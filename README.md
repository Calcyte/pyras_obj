# pyras_obj
This is a real time OpenGL rasterizor programmed in Python. It currently only renders .OBJ files and their associated file types (.MTL and texture files).
Texture files must be .JPEG or .PNG. Camera controls are based off mouse movement, and the movement keys are WASD as per most video games.This program currently does not work on devices with multiple monitors, it will always display on DP1 or HDMI1.
